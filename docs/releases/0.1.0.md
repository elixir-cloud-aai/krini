The first release of Krini, rewritten as a Next.js web app: browse the GA4GH
services of a Cloud Registry, log in with any OpenID Connect provider (LS
Login for ELIXIR On-Cloud), and run tasks on GA4GH Task Execution Service
(TES) and workflows on GA4GH Workflow Execution Service (WES) instances with
your own access token. Krini is published as a signed container image,
`docker.io/elixircloud/krini:0.1.0`, that takes all its settings when it
starts, and a signed Helm chart attached to this release; the
[documentation](https://krini.readthedocs.io/en/latest/) covers its use,
deployment and configuration.

## Features

- Browse the services of a Cloud Registry, and run and follow WES workflows on them, in the rewritten Next.js app (#40, #42, #61)
- Run, follow and cancel TES tasks, with your access token sent with every TES and WES request, on Cloud Components 2.0.0-alpha.51 (#41, #44, #91, #90)
- Open the details of a WES run (state, logs, outputs) from the run list (#66, #100)
- Start from a minimal dashboard that leads to tasks and workflows (#67, #108)
- Log in with any OpenID Connect provider, with access tiers from group claims and a link to request compute access (#43, #45, #70)
- Copy your access token for the CLI and APIs (#46, #61)
- Keep the light or dark theme over reloads (#13, #61)
- Read a privacy notice, reachable before login and set up per deployment (#9, #64)
- Deploy Krini with a Helm chart, released and signed with each version (#52, #92, #94, #95)
